# Upwork portfolio entry

## Ice Hockey Match Analytics & Machine Learning

I developed an end-to-end sports analytics project using Python and scikit-learn to explore historical ice hockey results and evaluate home-team win prediction.

**What the project includes**
- Data cleaning and quality checks
- Exploratory data analysis and visualizations
- Team and season scoring analysis
- Pre-match historical form features
- Logistic Regression and Random Forest models
- Chronological train/test evaluation
- Confusion matrix, ROC curve, and classification metrics
- Reproducible Google Colab notebook and documented workflow

**Tools:** Python, pandas, NumPy, Matplotlib, Seaborn, scikit-learn, Excel, Google Colab.

**Deliverables:** Notebook, analysis charts, model comparison table, sample predictions, and project documentation.

Note: Model performance should be reported using the actual results from the notebook. This is a demonstration project and not a guarantee of future match outcomes.
